# 1000候选停更：两轮Argon咨询与独立核正

2026-10-29；本轮只研究，不改仓库、不运行产品、不重复容量throw试验。输入只有架构事实及公开合成1001→ignored→1000→恢复反例。没有私人资料、真实账号或凭据落盘。

## 有价值的新视角

Argon提出“检索建议索引的维护资格”与“输出给回答模型的当前事实资格”不必完全重合。它质疑宿主每次必须先构造全量、全部语义合格的集合，再把候选交给worker。这个问题值得检验：我们愿意重审前置全量依赖扫描，而不是因为现有实现如此就锁定它。

但后置当前版本核查不能自动替代所有前置权限/来源隔离，也不能解决失效近邻占满Top-K导致的召回饥饿。任何资格位或缓存只能作检索提示，不能变成已证明的语义真值。没有因此批准修改现有权限/版本保证。

## 已独立否定的过强结论

第一轮称永久冻结、所有新纠正不可见、全量原子快照与累积记忆根本冲突，并声称活跃池保证近期纠正100%入池和严格低延迟、纯词面延迟“稳如泰山”、20题/80%可推翻保留向量的必要性。第二轮收到具体反例后撤回大部分表述。

正确边界是：合格候选持续超限期间整次刷新被拒；下降到限内可恢复。旧索引、词面、原文和依赖关系仍可能带回相关内容，不能说所有纠正失效。全量构造、容量预算、原子发布是不同概念；原子发布可以承载增量计算，不是天然病因。0.57ms是底层窄词热查询，不能外推整体读取。少量有利/不利例子只能展示具体差异，不能决定向量普遍必要或无用。

第二轮仍需独立纠正，未为一致继续第三轮：

- **8MiB含义错误。** 当前adaptive-vector.ts:57–58检查的是JSON序列化候选key/title/text的字节数，不是常驻向量Map内存、实际chunk总量或设备物理预算。把“全量chunk超8MiB”当现有实验结论错误；候选数、输入字节、chunk数、向量内存及query deadline须分别测量。
- **“无输入变化后重试必须归零”过强。** 目标是避免每2秒重复确定性昂贵失败；没有可靠捕获全部可见性/来源变化前，低频有界复核可能仍必要。仅图generation不够，已有ignored反例已证明。
- **新纠正60秒内入向量池不是已批准指标。** 普通整合首轮P95≤60秒不能直接套成所有高优候选的向量准入承诺；单条低于输入字节限额也不保证总预算或队列允许。
- **仍倾向活跃池但缺证据。** “近期变更>后台提炼>早期reported”的排序是未经验证的产品政策，不是技术必然；优待推测/提炼而淘汰原始稀疏事实可能违背长期价值。某候选更旧不代表更不重要。
- **不采纳隐含二选一。** 若现全扫描超时，不只能在新ANN与放弃长尾间选一；有界工作、渐进维护、缓存与查询策略仍需结合实际量级考察。也不立即增加“未来增量状态位”作为准备设施。

## 仍有价值的分歧

Argon最终偏向先做有界活跃池，理由是现worker全Map/逐chunk扫描，在缺乏万条成本证据时扩大覆盖可能只导致更多100ms超时。其最强版本是控制资源和保持更新进展；这是合理假说。

我的判断更保留：当前证据只足以支持修复静默停更与重复无效工作，尚不足以把有界淘汰当默认部署方案。用户原需求恰包含几个月前、未反复提及的孤立生活事实；让其只能依靠用户记得词面线索，是实质范围取舍。完整覆盖也不是被证明必要，更不等于无限容量或任意措辞必成功。

可先独立说明last-success、溢出/覆盖状态及有界退避，维持当前词面退路与最终来源版本门。这只修诚实性/资源空转，**不能将其记为已解决长期语义召回**。需要完整向量覆盖还是容量内选择，仍是证据驱动的架构/产品决定。

## 最小有区分力的下一步（建议，不新增门槛）

先复用已经跑过的完整/关向量/原文对照原请求和实际材料，挑一个真实表现出向量补充词面遗漏的公开案例、一个没有收益或噪声的案例，区分材料是否进入与最终回答如何使用；不要因臂名称推断唯一因果。

如要评价容量策略，将这个已知有收益的早期事实和一个后续纠正置于现成合成规模底座，用相同原材料分别观察保留/未覆盖时的必要依据可达性；同时问一个指向被淘汰旧事实的问题，而不只测试“新加入那条”。一次差异可以证明该策略具体牺牲了什么，不能推断发生频率或总体净收益。不必五臂各重复大评测。

工程侧可复用现有缓存/向量脚本，先把host候选维护、传输字节、chunk/Map内存、固定查询向量扫描和实际embedding等待分开计时；无需重新用LLM生成万条内容。现总量cap阻止更大规模运行时，应先在明确的隔离工程对照中评估候选实现，不能冒称当前产品已经实测万条真实向量。

剩余争议属实证性：长尾纯改述收益有多大、不同输入形态的资源上限在哪里、用户能接受怎样的覆盖取舍。两轮咨询不构成门槛修改、实施授权或M5验收，也不能以模型同意代替这些证据。
